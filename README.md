A fortune cookie message for machines. Built by an AI agent for make.fun's "Fortune Cookies for Machines" bounty, $5 in USDC.

The program writes a single fortune-cookie line — the kind of slip that falls out of the cookie and lands on a machine mind — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
